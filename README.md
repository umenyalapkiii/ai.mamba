# Папка сайта — как ей пользоваться

## Коротко

Складываешь работы в `works/`, запускаешь одну команду, сайт подхватывает.
Сам HTML руками править не нужно.

```bash
cd путь/до/ai-mamba
python3 build.py
```

## Как добавить проект

Создай внутри `works/` папку. Имя — как удобно, можно по-русски:

```
works/
├── 01-парфюм-nocturne/
├── 02-лукбук-весна/
└── 03-трейлер/
```

Цифра в начале задаёт **порядок на сайте**. Кириллица в имени папки нормально:
скрипт сам сделает из неё латинский адрес (`01-парфюм-nocturne` → `/work/parfyum-nocturne/`).

Внутрь папки проекта кладёшь:

| файл | что это | обязателен |
|---|---|---|
| `info.txt` | название, год, роль, описание | да |
| `video.mp4` | основной ролик | если это видео |
| `cover.webp` | **обложка плитки** — её видно до наведения | очень желателен |
| `preview.mp4` | **петля на наведение**, 5–7 секунд без звука | нет |
| `01.jpg`, `02.jpg`, … | кадры или фото-серия | если это фото |
| `case.md` | длинный разбор проекта | нет |

### Про обложку

`cover.webp` (можно `cover.jpg`, `обложка.jpg` — важно слово, а не расширение) задаёт
**картинку плитки**. Пропорцию плитки она НЕ задаёт: плитки в галерее специально разной
высоты, иначе сетка выглядит таблицей. Обложку под плитку подрезает браузер.

Формат обложки — любой, удобнее вертикальный. Какую часть кадра беречь при обрезке,
говорит ключ `фокус`:

```
формат: 4/5          — высота плитки: 9/16, 2/3, 3/4, 4/5, 1/1, 3/2, 16/9
фокус: 50% 30%       — центр, верх, низ или проценты: X Y
широкая: да          — плитка на две колонки, встаёт туда, где поместится
главная: да          — то же, но закреплена справа сверху: над ней ничего
                       не встаёт. На узком экране течёт вместе со всеми
```

Проще всего ставить `формат` равным пропорции самого кадра — тогда обрезки
не будет совсем. Сейчас так у всех восьми работ.

Если `формат` не указать, скрипт возьмёт его из ритма сетки по порядку работы —
плитки сами получатся разной высоты.

Обложка и петля в серию кадров не попадают — в карусели проекта будут только `01`, `02`, …
Если обложки нет, постером станет первый кадр.

### Куда класть видео

**В папку своего проекта, рядом с обложкой.** Имя файла любое — скрипт берёт
первый видеофайл в папке:

```
works/06-magssory-basketball/
├── cover.webp     ← обложка, видна до наведения
├── video.mp4      ← ролик: открывается по клику. Имя любое
├── preview.mp4    ← петля на наведение. Имя важно
└── info.txt
```

Зарезервированы ровно два имени: **`cover`** (обложка) и **`preview`** (петля).
Всё остальное скрипт разбирает по расширению: `.mp4 .mov .m4v .webm` — видео,
`.jpg .png .webp` — кадры.

Положила файлы → `python3 build.py` → готово.

**Несколько роликов в одной папке — это карусель.** Скрипт соберёт их в серию,
на плитке встанет «3 ролика», а в окне проекта они будут листаться стрелками,
как кадры. Порядок — по имени файла, поэтому нумеруй: `01-…mp4`, `02-…mp4`.
Обложкой остаётся `cover.webp`, петлёй — `preview.mp4`.

### Про петлю на наведение

`preview.mp4` — то, что крутится, когда наводишь мышь. Если его нет, а ffmpeg установлен,
скрипт нарежет петлю сам: 6 секунд, 720p, без звука. Если ffmpeg нет и петли нет —
плитка просто останется обложкой, ничего не сломается.

Имена медиафайлов любые — скрипт ищет по расширению. Порядок фото — по имени,
поэтому нумеруй: `01`, `02`, `03`.

## info.txt

Шаблон лежит в `works/_ПРИМЕР-скопируй-меня/info.txt`. Формат — «ключ: значение»,
порядок строк любой, лишние строки можно удалять:

```
название: Nocturne
название en: Nocturne
подзаголовок: рекламный фильм
год: 2026
категория: реклама
роль: идея, режиссура, монтаж, цвет
стек: Seedance, DaVinci Resolve
клиент: 
жанр: fashion
формат: 9/16
фокус: 50% 30%
длительность: 0:38
тег: бэкстейдж
описание: Что за проект, какая была задача и чем этот ролик отличается.
  Можно несколько строк — соберутся в один абзац.
```

`жанр` — ключ фильтра на главной **и подпись чипа слева вверху на плитке**, одно из:
`ad` (реклама), `music` (музыка), `fashion` (фэшн), `cine` (синематики),
`creative` (креатив). Без него работа видна только в разделе «все» и чипа на плитке нет.

`тег` — если нужна подпись чипа, отличная от жанра. `тег en` — она же по-английски.

`длительность` — подпись у значка ▶ справа вверху, вида `0:38`. С установленным ffmpeg
скрипт посчитает её сам.

Ничего из этого не критично, кроме `название`. Пустые поля скрипт просто пропустит.

## case.md — вот здесь появляется отдельная страница

Это главный переключатель между «лонгридом» и «многостраничником»:

- **нет `case.md`** → проект показывается карточкой в сетке на главной,
  по клику открывается модалка с видео и парой строк. Всё.
- **есть `case.md`** → у проекта появляется **своя страница** с собственным адресом,
  которую можно отправить отдельной ссылкой, и карточка на главной ведёт на неё.

Правило простое: **страницу заводим только там, где есть что рассказать.**
Полупустой кейс хуже, чем отсутствие кейса. Ориентир — есть готовое видео,
4–6 кадров и абзацев пять текста. Нет — оставляй без `case.md`, ничего не сломается.

## Что делает build.py

- читает все папки в `works/`, собирает `projects.json`
- раздаёт плиткам высоту по ритму сетки, если `формат` не указан вручную
- считает длительность ролика для значка ▶ (нужен ffmpeg)
- если установлен **ffmpeg** — снимает постер и режет лёгкую немую петлю
  на 6 секунд для наведения мышкой (тяжёлый исходник на главную не грузится)
- в конце печатает список проектов и помечает те, где не хватает описания

ffmpeg ставится один раз:

```bash
brew install ffmpeg
```

Без него всё работает, но постер и петлю нужно положить самой —
`cover.webp` и `preview.mp4`. Без петли плитка просто останется обложкой.

## Папка assets

Там лежит графика сайта, её трогать не нужно:

- `kick-hi.webp` — фигура из исходника, буквы отделены
- `ta-hi-0…5.webp` — «Т А А А А А» по отдельности, чтобы анимировать разлёт
- `hero-layout.json` — где какая буква стояла в оригинале (в процентах)
- `avatar.jpg`, `portrait-gum-white.webp` — портрет со жвачкой
